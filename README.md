# ERP System

A full-stack ERP/HR management system built with a TypeScript frontend and a C# backend.

## Overview

This project focuses on core human resource and administrative workflows, including:

- Employee management
- Department management
- Attendance tracking
- Leave request management
- Payroll management
- Reporting and analytics
- Role-based access for Admin, HR, Manager, and Employee users

## Tech Stack

- **Frontend:** TypeScript, React, Vite, Material UI
- **Backend:** C#, ASP.NET Core, Entity Framework Core
- **Database:** PostgreSQL with Npgsql

## Project Structure

- `frontend/ERP.Client` — Web client application
- `backend/ERP.Api` — API and data access layer

## Features

### Dashboard
Provides a summary of employee, attendance, leave, and payroll data.

### Employees
Create, edit, search, and manage employee records.

### Departments
Manage departments and department descriptions.

### Attendance
Track employee check-in/check-out records and attendance status.

### Leave
Review and manage employee leave requests.

### Payroll
Generate and manage payroll entries with salary, allowances, overtime, and deductions.

### Reports
View summary reports across employees, departments, attendance, leave, and payroll.

## Getting Started

1. Clone the repository
2. Install frontend dependencies
3. Restore backend packages
4. Configure environment variables and database connection
5. Run the backend API
6. Run the frontend client
